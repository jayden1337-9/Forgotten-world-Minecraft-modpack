# The Forgotten Abyss

Build a 4x5 frame from Abyss Portal Frame blocks, leaving a 2x3 opening. Place an Abyss Keystone in the lower-left opening to activate the portal. Walking into the portal sends the player to `forgotten:forgotten_abyss`. A return portal is generated at the Shattered Landing hub.

The dimension uses a void generator. On first entry the script builds a floating deepslate island, a blackstone landing platform, four light pillars, a shrine and an Abyss Watcher guardian.

## First custom model
- Entity: `forgotten:abyss_watcher`
- Geometry: `resource_pack/models/entity/abyss_watcher.geo.json`
- Texture: `resource_pack/textures/entity/abyss_watcher.png`
- Animation and controller JSON are included in the Resource Pack.

The portal is built from craftable custom blocks and replaces the old chat-phrase entrance. This is the first playable hub, not the complete planned dimension. More regions, dungeons, settlements and creatures are future milestones. Test on a disposable world and note the exact Bedrock retail version.
