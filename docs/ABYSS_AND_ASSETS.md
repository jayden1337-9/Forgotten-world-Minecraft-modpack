# The Forgotten Abyss

Enter the exact chat phrase `LET ME IN MOMMY`. The phrase is intercepted before broadcast and the sender is teleported to `forgotten:forgotten_abyss`.

The dimension uses a void generator. On first entry the script builds a floating deepslate island, a blackstone landing platform, four light pillars, a shrine and an Abyss Watcher guardian.

## First custom model
- Entity: `forgotten:abyss_watcher`
- Geometry: `resource_pack/models/entity/abyss_watcher.geo.json`
- Texture: `resource_pack/textures/entity/abyss_watcher.png`
- Animation and controller JSON are included in the Resource Pack.

This is the first playable hub, not the complete planned dimension. More regions, dungeons, settlements and creatures are future milestones. Test on a disposable world and note the exact Bedrock retail version.
