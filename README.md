# The Forgotten World

A lightweight medieval-fantasy RPG add-on for Minecraft Bedrock Edition.

## Repository contents

- `behavior_pack/` — gameplay data and systems
- `resource_pack/` — textures, models, animations, sounds and UI
- `config/` — rarity and guild progression configuration
- `docs/` — project plan and implementation notes

## Current foundation

- Behavior Pack and Resource Pack manifests
- Seven rarity tiers: Common through Divine
- Guild ranks: F through SS
- Initial implementation roadmap

## Getting started

1. Download or clone this repository.
2. Import the Behavior Pack and Resource Pack folders into the appropriate Minecraft Bedrock development pack locations.
3. Open a test world and enable both packs.
4. Check the Content Log if Minecraft reports a manifest or JSON issue.

The packs currently provide a project skeleton and configuration data; gameplay systems and custom assets are added in later milestones.

See [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md) for the roadmap.
